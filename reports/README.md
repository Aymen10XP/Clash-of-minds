# Generated quality evidence

This directory contains reports generated by real executions on 19 November 2026. It is evidence for the ISO/IEC 25010 student assessment, not a claim of formal ISO certification.

| Directory | Evidence |
| --- | --- |
| `generated/tests/` | Vitest JUnit, frontend log, 66-test Django log, and Cypress Chrome/Firefox log |
| `generated/coverage/` | Backend coverage summary and Cobertura XML (80%) |

| `dast/` | OWASP ZAP frontend baseline and Django active-scan HTML/JSON reports |

`generated/summary.json` records commands, timestamps, durations, exit codes, platform, and tool results for the repeatable core evidence run.

## Reproduce core evidence

Install dependencies and start Docker Desktop, then run:

```powershell
npm install
.\.venv\Scripts\python.exe -m pip install -r server\requirements-dev.txt
npm run evidence:full
```

This reruns client tests, backend tests and coverage, ESLint, Bandit, npm and pip dependency audits, Django checks, migration drift, production build, and Cypress in Chrome and Firefox.

## Reproduce performance and DAST evidence

Seed and start the backend first:

```powershell
npm run seed:demo
$env:DJANGO_ALLOWED_HOSTS='localhost,127.0.0.1,host.docker.internal'
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload
```

In another terminal, run the commands documented in `docs/INSTALLATION_AND_EXECUTION_GUIDE.md`. The committed reports preserve the measured result; reruns can vary with hardware and current advisories.
